# ⚡ 极速 SQL 日志分析器 (sqllog CLI)

一款针对 ERP / YES 平台深度定制的高性能 SQL 日志分析与可视化诊断工具。基于 **Node.js** 与 **DuckDB 纯内存分析引擎 (C++ 向量执行)** 构建，能够在 1 秒内完成数十万行海量日志的结构化解析、归一化聚合与 N+1 循环诊断。

---

## 🚀 快速安装与使用

### ⚙️ 环境要求
- **Node.js**：建议使用 **Node.js 24** 或更高版本（推荐 v24+）

---

### 1. 🌟【最推荐·团队内部】直接通过 GitHub 全局安装 (无需发布 npm)

团队成员只要电脑安装了 Node.js，**无需发布到 npm**，在终端运行以下命令即可全局安装：

```bash
npm install -g git+https://github.com/believe-pxw/analyzeSqlLog.git --allow-git=all --allow-scripts=duckdb
```

**使用方法**：
在电脑任意存放日志的目录，直接在终端敲：
```bash
sqllog .
```
或者分析指定的日志目录/日志文件（支持 `.log` 文本日志及 `.log.gz` 压缩日志）：
```bash
sqllog "D:\Users\boke\Desktop\source\bokeerp\erp-backend\logs"
```
程序会自动拉起 DuckDB 纯内存引擎解析，并在默认浏览器中自动弹出极简可视化控制台（如 `http://localhost:3000`）！

---

### 2. 📦 开发者源码本地运行

```bash
# 克隆仓库
git clone https://github.com/believe-pxw/analyzeSqlLog.git
cd analyzeSqlLog

# 安装依赖
npm install

# 本地运行
node index.js "D:\path\to\logs"
```

## 🌟 核心功能与六大分析面板

系统采用极致紧凑的视觉设计与响应式布局，提供以下六大核心分析面板：

| 面板 | 名称 | 核心功能与亮点 |
| :--- | :--- | :--- |
| **Tab 1** | **🔁 事务内重复 SQL (N+1) 诊断** | **(默认首页)** 基于日志中 `dbManager` 内存对象句柄（如 `MySqlDBManager@7b2aa7e0`），抓取在**【同一数据库事务内】**重复调用的 SQL 模板。支持**自由手填重复次数阈值（`>= N 次`）**，提供 `IN(...)` 批量化与缓存重构建议，支持一键点击「🔍 查看调用」跳转明细。 |
| **Tab 2** | **🐢 慢 SQL 排行** | 按单次执行耗时降序排列，快速找出拖慢系统响应的瓶颈 SQL。支持**自由手填耗时阈值（`>= N ms`）**，一键直达 VSCode 源码/日志精准行号，支持 TraceID 一键下钻。 |
| **Tab 3** | **🔗 Trace 链路分析** | 完整还原单次请求生命周期内的全部 SQL 执行序列（默认 50 条/页）。支持**【时间列】**与**【耗时列】**经典表头极简点击双向排序（时间升序/降序、耗时降序/升序）。 |
| **Tab 4** | **📊 SQL 频次榜** | 对全局参数化 SQL 模板进行归一化频次统计，汇总总耗时、平均耗时、最大耗时与 Trace 数，支持一键点击「🔍 查看调用」跳转明细。 |
| **Tab 5** | **📋 SQL 调用明细** | 展示某条特定 SQL 模板在全局中的每一笔具体调用记录。顶部呈现完整过滤上下文标签（准确标注来源：频次榜或 N+1 诊断、TraceID、dbManager 事务句柄 Hash、循环次数等），显示精准日志行号和源文件绝对路径。 |
| **Tab 6** | **📈 概览统计分析** | 汇聚分析 SQL 总数、归一模板数、最高慢 SQL 耗时、独立 Trace 动作数、总耗时与日志扫描解析性能指标。 |

## 🖥️ 极速流畅的交互与 UI 体验

1. **📎 VSCode 源码与日志行号直达跳转 (`vscode://file/`)**：
   - 自动在解析时记录 SQL 语句出现的精准日志行号（`line_number`）与源文件路径（`source_file`）；
   - 在慢 SQL、Trace 链路、SQL 调用明细等全表格中，点击定位链接即可直接拉起 VSCode 并高亮跳转到该行；
   - 针对 `.gz` 压缩日志，后台自动解压至临时目录并无缝唤起 VSCode 打开解压后的日志文件。

2. **🖱️ 0ms 瞬间列名折叠/展开**：
   - 针对包含数十列的超长 `SELECT` 语句，算法自动将冗长列名缩略为 `select ... from <原表与条件>`；
   - **左键点击 SQL 框**：0ms 纯粹秒切展开完整 SQL 与收起缩略 SQL；
   - 采用 `\bfrom\b` 单词界定符，保证不把列名中含有的 `Formula` / `FromDate` 等字符误解为 SQL 的 `FROM` 关键字。

3. **📊 全系统一标准 UI 分页**：
   - 5 大数据表格全系接入完全统一的标准分页 UI 组件，支持 `15 / 20 / 50 / 100 / 200 / 500` 条/页自由切换。

4. **✨ 绝对平滑视口与零抖动**：
   - CSS `html { overflow-y: scroll; }` 锁定纵向滚动条槽位，消除页面内容增减引发的全屏横向抖动；
   - 容器 `min-height: 360px` 稳定框架高度，跨面板按钮跳转采用 `skipAutoLoad` 杜绝重复并发重绘，保持 Viewport 视口绝对平稳。

5. **📋 桌面级极简右键菜单**：
   - **右键点击任意 SQL 框**：自动弹出位置精准的自定义极简右键菜单，提供 **【📋 复制完整 SQL】** 单一最核心选项，一键写入剪贴板并附带 Floating Toast 提示。
